# SFV-X Tools — دليل المشروع والنشر

موقع **Static بالكامل** (HTML + CSS + JavaScript) بدون Backend: سريع، رخيص، وآمن. فيه **35 أداة**، صفحة مستقلة لكل أداة، بالعربية والإنجليزية (**74 صفحة**).

## 1) الرفع الفوري (بدون أي تثبيت)

كل ما تحتاجه موجود جاهزاً داخل مجلد **`dist/`**. ارفع محتوياته (وليس المجلد نفسه) على جذر الدومين:

| الاستضافة | الطريقة |
|---|---|
| **Cloudflare Pages** (موصى بها) | Create project → Direct Upload → اسحب مجلد `dist` |
| **Netlify** | app.netlify.com/drop → اسحب مجلد `dist` |
| **GitHub Pages** | ارفع محتوى `dist` إلى مستودع، ثم Settings → Pages |
| **أي استضافة عادية** | ارفع محتوى `dist` إلى `public_html` |

> الموقع يستخدم مسارات من الجذر (`/tools/...`) لذلك يجب أن يعمل على **دومين أو دومين فرعي** وليس داخل مجلد فرعي.

## 2) التعديلات الإلزامية قبل الإطلاق (3 أشياء)

افتح **`site.config.json`** وعدّل:

```json
{
  "domain": "https://دومينك-الحقيقي.com",   ← مهم جداً للـ SEO (canonical / sitemap / hreflang)
  "whatsapp": "رقمك بالصيغة الدولية بدون +",  ← مثال: 201012345678
  "platforms": { "home": "...", "games": "...", "news": "...", "movies": "...", "store": "..." }  ← روابط منصاتك الفعلية
}
```

ثم أعد البناء:

```bash
npm install      # مرة واحدة (يثبّت jsdom فقط، لأداة البناء)
npm run build    # يعيد توليد مجلد dist بالكامل
npm test         # اختياري: 66 اختبار للأدوات
```

ثم ارفع `dist` من جديد.

> القيم الحالية (`sfvx.tools` ورقم `201000000000` وروابط `sfvx.com`) **أمثلة وهمية**.

## 3) بنية المشروع

```
dist/                    ← ما ترفعه للاستضافة
  index.html             الرئيسية (عربي)
  services/              صفحة الخدمات
  tools/<tool-id>/       صفحة لكل أداة (35 صفحة)
  en/...                 النسخة الإنجليزية بنفس البنية
  assets/app.js          كل منطق الأدوات والترجمة
  assets/style.css       التصميم
  sitemap.xml  robots.txt  manifest.webmanifest  sw.js  404.html  _headers  icon.svg
src/app.js, src/style.css   المصدر (يُنسخ إلى dist/assets عند البناء)
build.js lib.js test.js     أدوات البناء والاختبار
site.config.json            الإعدادات
```

## 4) كيف تضيف أداة جديدة؟

1. افتح `src/app.js` وأضف عنصراً في مصفوفة `T` (استخدم `IO(...)` لأدوات النص أو `F(...)` للأدوات المخصصة، وانظر الأدوات الموجودة كأمثلة).
2. أضف اسمها ووصفها بالإنجليزية في النص `const EN={}` (صيغة: `id|Name|Description`).
3. شغّل `npm run build` — ستُنشأ صفحتها العربية والإنجليزية، وتُضاف تلقائياً للـ sitemap.

لتغيير الخدمات أو الأسعار أو نسب الأرباح عدّل `SV` و`D.ar.rv1/rv2` و`D.en.rv1/rv2` في الملف نفسه.

## 5) الـ SEO — ما هو جاهز وما تفعله أنت

**جاهز:** Title/Description فريد لكل صفحة · Canonical · hreflang (ar/en/x-default) · Open Graph + Twitter Card · Schema.org (WebApplication, BreadcrumbList, FAQPage, ItemList) · محتوى مُولَّد مسبقاً (SSG) ليراه الزاحف بدون JavaScript · روابط داخلية لكل الأدوات · sitemap.xml مع hreflang · robots.txt · PWA يعمل دون اتصال.

**عليك:**
1. سجّل الموقع في **Google Search Console** وأرسل `https://دومينك/sitemap.xml`.
2. أضف صورة مشاركة `og:image` (1200×630 بصيغة PNG/JPG) إن أردت معاينة جميلة على السوشيال.
3. (اختياري) أضف Analytics خفيفاً مثل Plausible أو Cloudflare Web Analytics لمعرفة الأدوات الأكثر استخداماً فعلاً — قائمة «الأكثر استخداماً» الحالية مختارة يدوياً في `POP`.

## 6) ملاحظات تقنية صريحة

- **حفظ الصور والملفات** (ضغط الصور، robots.txt…): في المعاينة داخل Claude يعمل عبر نافذة تأكيد؛ على موقعك الحقيقي يُحفظ الملف مباشرة. إن لم يتوفر الحفظ يعرض الزر رسالة ويمكنك نسخ النتيجة.
- **فاحص Meta Tags** يعمل بلصق كود HTML؛ جلب موقع خارجي بالرابط مباشرة يمنعه المتصفح (CORS). الحل لاحقاً: Cloudflare Worker صغير كوسيط.
- نصوص داخل بعض الأدوات (أزرار وأمثلة وحقول إدخال) ما زالت بالعربية فقط؛ الأسماء والأوصاف والصفحات مترجمة بالكامل.
- خدمة تأليف القصص: نسب الأرباح (5% / 15%) معروضة كما حددتها؛ يُنصح بصياغة **عقد مكتوب** يوضح ملكية الحقوق وطريقة الحساب.
- تصميم الواجهة بـ CSS خاص (بدون Tailwind) لتقليل الحجم وتسريع التحميل.
